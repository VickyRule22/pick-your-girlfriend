# Pick Your Girlfriend

A retro doll-box picker, type samples and style guide for aitechgirlfriends.com, a collective of women who build with AI.

- Picker: https://vickyrule22.github.io/pick-your-girlfriend/
- Style guide: https://vickyrule22.github.io/pick-your-girlfriend/style-guide/ (Markdown: style-guide/STYLE_GUIDE.md)

Concept prototype. The doll photos are AI-generated stand-ins, not any real toy brand. Built from `picker/` by `build.py`.
